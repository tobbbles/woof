# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

If you discover a security vulnerability in Woof, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, use one of the following:

- **GitHub Security Advisories** — [Report a vulnerability](../../security/advisories/new) directly through GitHub's private disclosure process.
- **Email** — Send details to the maintainers listed in the repository.

### What to include

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- The affected version(s)

### What to expect

- **Acknowledgement** within 48 hours of your report
- **Status update** within 7 days with an assessment and remediation plan
- **Fix timeline** — Critical vulnerabilities will be patched as soon as possible; non-critical issues will be addressed in the next release

We will credit reporters in the release notes unless you prefer to remain anonymous.
